# EZRA ERP

Sistema SaaS multiempresa de gestão comercial. Controla a operação de ponta a ponta: clientes, produtos, fornecedores, orçamentos, pedidos, vendas, estoque, depósitos, compras, entregas, financeiro e dashboards, com suporte a múltiplas empresas, filiais e depósitos.

Desenvolvido por EZRA.

## Stack

- TypeScript, React (TanStack Start) e Vite
- Supabase (banco de dados e autenticação)
- Tailwind CSS e componentes Radix/shadcn

## Testes

Mais de 80 arquivos de teste cobrem regras de negócio como PDV, estoque, financeiro e operação offline.

```bash
npm test
```

## Rodar localmente

```bash
npm install
npm run dev
```
